## Contexte

Div-In est une application mobile communautaire pour les plongeurs. Elle permet de consigner ses plongées, de suivre sa progression et de partager des informations, avec pour ambition de mettre en relation plongeurs et centres de plongée.

## Mon rôle

J'ai rejoint le projet comme développeur full-stack de soutien, d'août 2025 à mars 2026. Je n'étais pas le développeur principal : ma mission était d'ajouter des fonctionnalités à l'application mobile et de corriger les problèmes existants.

## Sur quoi j'ai travaillé

- **Fonctionnalités mobiles** : écrans nouveaux ou ajustés en React Native (formulaires, listes, navigation), avec validation des saisies et états d'erreur et de chargement clairs.
- **Correction de bugs** : identification et correction de problèmes sur des écrans existants.
- **Intégration de l'API** : connexion de l'app à de nouveaux endpoints Laravel et adaptation des appels existants, gestion des réponses et des erreurs côté mobile.
- **Détails d'UX** : retours plus clairs pour chaque état (chargement, succès, erreur), meilleurs libellés et messages d'erreur, navigation retour plus fluide.
- **Documentation** : documentation technique rédigée et structurée sur l'architecture (React Native, Laravel, base de données), les écrans et parcours clés, les endpoints de l'API et les règles métier, pour faciliter l'arrivée de nouveaux développeurs.

## Stack

- **Mobile** : React Native, JavaScript, composants UI sur mesure.
- **Back** : Laravel, API REST, MySQL / MariaDB.
- **Workflow** : Git et GitHub, suivi des tickets, documentation versionnée avec le code.

## Statut

J'ai arrêté de travailler sur le projet en mars 2026. Il s'agit d'un projet privé : le code et la documentation technique ne sont pas publics.
