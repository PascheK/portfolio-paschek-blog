> My previous roadmap was about preparing an internship abroad. That part happened, and a few other things changed along the way. This is the updated version: where I am, what is behind me, and what I want next.

## 1. Where I am

- I **passed my Maturité**, which I finished in June 2026.
- I got a **scholarship** that lets me travel to Japan and work there.
- Since July I've been working as a **full-stack developer at HelloXLab, in Osaka**.
- I live in Osaka until **10 January 2027**.

At HelloXLab I was asked to make Space Builder production ready. I moved it from Electron to Tauri, redesigned its interface, built the licensing and payments server (MRSV Core) in Rust, wrote a Rust SDK shared by the server and the apps, and set up the DigitalOcean and GitHub environment that deploys them. The details are in the [projects](/en/projects).

---

## 2. What changed since the last roadmap

- The **internship abroad** I was preparing is no longer a plan: it's what I'm doing now.
- My first game, the [2D survival RPG](/en/blog/unity-survival-rpg), is **on hold**.
- **PascheK-ChatBox** is a project I no longer use day to day.
- Some of the side projects I listed back then simply didn't survive the year, and that's fine.

---

## 3. What's next: back in Switzerland

I come back to Switzerland in January. The plan is simple:

- **Find a job**, if I can.
- Keep working on my **video game in parallel**, alongside that job.

I don't have more certainty than that today, and I'd rather say so than invent a plan.

---

## 4. The game

The game I want to keep working on is a new, much smaller 3D game starring my hamster, Bouboulle. It started as a way to use what I was learning in Blender, and I'm documenting it in devlogs so that I actually finish it. It starts with [Devlog #0](/en/blog/devlog-0).

---

## 5. Everything else

- **Homelab**: it keeps running, and monitoring and more infrastructure as code are still on my list.
- **This portfolio**: it keeps evolving, and it's where I'll keep documenting what I do.

---

## 6. Realities

Moving back, looking for work and building a game on the side will not all move at the same speed. Some things will progress in spikes, others will sleep for a few months. That's fine: the direction matters more than the pace.

I'll keep writing about it here.
