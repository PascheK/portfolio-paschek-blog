## Context

Div-In is a community mobile app for divers. It lets people log their dives, follow their progress and share information, with the longer-term goal of connecting divers and dive centres.

## My role

I joined as a supporting full-stack developer, from August 2025 to March 2026. I was not the lead developer: my job was to add features to the mobile app and to fix the problems that already existed.

## What I worked on

- **Mobile features**: new and adjusted screens in React Native, covering forms, lists and navigation, with input validation and clear error and loading states.
- **Bug fixing**: tracking down and correcting issues on existing screens.
- **API integration**: connecting the app to new Laravel endpoints and adapting existing calls, handling responses and errors on the mobile side.
- **UX details**: clearer feedback for each state (loading, success, error), better labels and error messages, smoother back navigation.
- **Documentation**: written and structured technical docs covering the architecture (React Native, Laravel, database), the key screens and flows, the API endpoints and the business rules, so new developers can get started faster.

## Stack

- **Mobile**: React Native, JavaScript, custom UI components.
- **Back end**: Laravel, REST API, MySQL / MariaDB.
- **Workflow**: Git and GitHub, issue tracking, documentation versioned with the code.

## Status

I stopped working on the project in March 2026. It is a private project: the code and the technical documentation are not public.
